# Open visual assets

`qr-workbench-calibration.png` is an original, text-free calibration backdrop generated for TP QR with OpenAI ImageGen. It contains no third-party logos, personal data, or QR payloads and is used only as a low-contrast workbench texture.

The application remains fully functional without this decorative asset; the QR preview and exports are rendered from code.

`homepage.png`, `workbench-navigation.png`, `workbench-mobile-codes.png`,
`workbench-editor.png`, and `public-content-text.png` are browser captures of
the public homepage and authenticated product using fictional local demo data.
They do not contain production accounts or personal content. The demo QR code
points only to the local application.
